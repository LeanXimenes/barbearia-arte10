Como colocar o site no ar

Barbearia Arte 10 · passo a passo para Windows
Seu projeto Supabase: iwekfmxrmmmxzjymtsyq

Resumo — são 4 etapas

  1. Criar o banco — colar um arquivo no Supabase e clicar em Run. (5 min)
  2. Colocar os dados da barbearia — endereço, WhatsApp e Instagram. (3 min)
  3. Publicar o site — gerar o site e arrastar para o Netlify. (10 min)
  4. Testar — fazer um agendamento de teste e limpar antes de divulgar. (5 min)

O aplicativo do barbeiro e os avisos no celular vêm depois (página final). O site funciona sem eles.

Tudo já está preparado neste computador A pasta do projeto é C:\arte10. O endereço e a chave pública do seu Supabase já estão configurados no arquivo C:\arte10\web\.env.
1

Criar o banco de dados

5 min
  1. Abra o editor de SQL do seu projeto (entre com sua conta do Supabase se pedir):
    https://supabase.com/dashboard/project/iwekfmxrmmmxzjymtsyq/sql/new
  2. No Windows, abra a pasta C:\arte10\supabase. Clique com o botão direito em instalar_tudo.sql → Abrir com → Bloco de Notas.
  3. No Bloco de Notas aperte Ctrl + A (seleciona tudo) e depois Ctrl + C (copia).
  4. Volte ao Supabase, clique dentro da área de texto do editor e aperte Ctrl + V (cola).
  5. Clique no botão verde Run (ou aperte Ctrl + Enter).
  6. O Supabase vai mostrar um aviso de "destructive operation". É normal: o arquivo só apaga coisas que ainda não existem, para poder ser rodado de novo com segurança. Clique em Run this query.
Deu certo quando… aparece embaixo, no resultado: "Barbearia Arte 10: banco instalado com sucesso." Se der algum erro no meio, pode rodar o arquivo inteiro de novo — ele não duplica nada.

Última coisa desta etapa — desligar o cadastro público (o site não usa login e ninguém precisa criar conta):

  1. Abra Authentication → Sign In / Providers.
  2. Desligue Allow new users to sign up e clique em Save.
2

Colocar os dados da barbearia

3 min

No mesmo editor de SQL, clique em New query, cole o texto abaixo, troque o que está entre aspas pelos seus dados e clique em Run:

-- Dados que aparecem no site (dá para mudar depois pelo app)
update public.config_barbearia set
  telefone_whatsapp = '17999999999',          -- só números, com DDD
  instagram         = 'barbeariaarte10',      -- sem o @
  endereco          = 'Rua Exemplo, 123 - Centro',
  cidade            = 'Sua Cidade',
  uf                = 'SP'
where id;

3

Publicar o site no Netlify

10 min

Parte A — gerar o site (cria a pasta com os arquivos prontos):

  1. Aperte a tecla Windows, digite PowerShell e aperte Enter.
  2. Digite os comandos abaixo, um de cada vez, apertando Enter depois de cada um:
cd C:\arte10\web
npm install        # só precisa na primeira vez (demora um pouco)
npm run build
Deu certo quando… aparece uma linha terminando com "built in …s". A pasta C:\arte10\web\dist foi criada.

Parte B — colocar no ar:

  1. Abra https://app.netlify.com/drop e crie uma conta grátis (pode entrar com o Google).
  2. Abra a pasta C:\arte10\web no Explorador de Arquivos e arraste a pasta dist para o quadro da página do Netlify.
  3. Em alguns segundos o site está no ar, com um endereço parecido com https://nome-aleatorio.netlify.app.
  4. Para escolher um nome melhor: Project configuration → Change project name (em telas antigas: Site configuration → Change site name) → por exemplo barbeariaarte10 → o site vira https://barbeariaarte10.netlify.app.
Para atualizar o site no futuro rode de novo npm run build no PowerShell e arraste a pasta dist na aba Deploys do seu site no Netlify.
Opcional — foto do site ao mandar o link no WhatsApp Depois de saber o endereço final, abra C:\arte10\web\.env no Bloco de Notas e acrescente uma linha VITE_SITE_URL=https://barbeariaarte10.netlify.app (com o seu endereço). Rode npm run build e arraste de novo.
4

Testar antes de divulgar

5 min
  1. Abra o endereço do seu site. Os serviços e os horários de funcionamento devem aparecer.
  2. Clique em Agendar horário, escolha um serviço, um dia e um horário.
  3. No nome, escreva algo que comece com TESTE (ex.: TESTE Leandro) e confirme. Deve aparecer "Agendamento confirmado!".
  4. Abra o agendamento de novo: o horário que você marcou agora aparece como "JÁ AGENDADO".
Importante: agendamento não se apaga Pela regra do sistema, nenhum agendamento de cliente pode ser apagado — nem pelo app. Por isso, antes de divulgar o site, apague os seus testes: no editor de SQL, abra C:\arte10\supabase\limpar_testes.sql (Bloco de Notas → Ctrl+A → Ctrl+C), cole e clique em Run. Ele apaga só os agendamentos cujo nome começa com TESTE. Depois que os clientes começarem a agendar, não use mais esse arquivo.

Se algo não funcionar

O que apareceO que fazer
Faixa amarela no topo do site: "Conexão com o banco não configurada" O arquivo C:\arte10\web\.env sumiu ou está vazio. Ele deve ter as duas linhas VITE_SUPABASE_URL e VITE_SUPABASE_PUBLISHABLE_KEY. Gere o site de novo (npm run build).
"Não conseguimos carregar os serviços agora" O banco ainda não foi instalado (etapa 1) ou deu erro no meio. Rode o instalar_tudo.sql de novo.
Endereço, WhatsApp ou Instagram não aparecem Faça a etapa 2. Campos em branco ficam escondidos de propósito.
Nenhum dia disponível no calendário Confira os horários de funcionamento e se há serviços ativos. Domingo é fechado.
"Muitos agendamentos em pouco tempo" É o freio contra robôs (20 agendamentos em 10 minutos). Em uso normal nunca aparece; nos testes, espere alguns minutos.
npm não é reconhecido no PowerShell Instale o Node.js (versão LTS) em nodejs.org, feche e abra o PowerShell de novo.

Depois: app do barbeiro e avisos no celular

O site já funciona sozinho. Quando quiser ligar o app do barbeiro (sem login, ele entra sozinho) e o aviso no celular a cada novo agendamento:

  1. Conta do app: em Authentication → Users → Add user → e-mail (ex.: app@barbeariaarte10.com.br) e uma senha longa. Marque Auto Confirm User. Depois libere a conta com o comando do arquivo docs\SUPABASE.md (seção 4).
  2. Gerar o app: preencha C:\arte10\android\local.properties (modelo em local.properties.exemplo) e siga docs\APLICATIVO.md.
  3. Avisos no celular: Firebase + a função notificar-agendamento + o arquivo supabase\ativar_push.sql (passo a passo em docs\SUPABASE.md, seção 6).
